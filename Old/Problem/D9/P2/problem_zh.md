# 内容

给定一棵以 1 为根的有根树，有 N 个节点和 N-1 条边。输出每个节点的所有孩子节点。

孩子表示法（Child Representation）将每个节点的所有孩子存储在一个列表中。对于有根树，每个非根节点有唯一父亲，但可以有多个孩子。要求每行输出格式为 `节点: 孩子列表`，孩子列表按编号升序排列；若无孩子则冒号后为空。

# 格式

## 输入

第一行一个整数 N（2 ≤ N ≤ 12），表示节点数。

接下来的 N-1 行，每行两个整数 u v（1 ≤ u, v ≤ N），表示 u 是 v 的父亲。

## 输出

输出 N 行，第 i 行格式为 `i: 孩子列表`，孩子之间用空格分隔，按编号升序排列。若某节点没有孩子，则冒号后不输出空格。

# 测例

```input1
5
1 2
1 3
2 4
2 5
```

```output1
1: 2 3
2: 4 5
3:
4:
5:
```
