# 内容

给定一棵以 1 为根的有根树，有 N 个节点和 N-1 条边。输出每个节点的深度。

一个节点的深度定义为从根节点（深度为 0）到该节点经过的边数。

# 格式

## 输入

第一行一个整数 N（2 ≤ N ≤ 12），表示节点数。

接下来的 N-1 行，每行两个整数 u v（1 ≤ u, v ≤ N），表示 u 是 v 的父亲。

## 输出

输出 N 行，第 i 行输出节点 i 的深度。

# 测例

```input1
7
1 2
1 3
2 4
2 5
3 6
3 7
```

```output1
0
1
1
2
2
2
2
```
