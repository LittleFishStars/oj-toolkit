# 内容

给定一棵以 1 为根的有根树，有 N 个节点和 N-1 条边。输出每个节点的父亲节点编号。根节点 1 的父亲记为 0。

父亲表示法（Parent Representation）是存储树的一种简单方式：使用一个一维数组 `parent[1..N]`，其中 `parent[i]` 表示节点 i 的父亲。

# 格式

## 输入

第一行一个整数 N（2 ≤ N ≤ 12），表示节点数。

接下来的 N-1 行，每行两个整数 u v（1 ≤ u, v ≤ N），表示 u 是 v 的父亲。

## 输出

输出 N 行，第 i 行输出节点 i 的父亲编号。

# 测例

```input1
5
1 2
1 3
2 4
2 5
```

```output1
0
1
1
2
2
```
