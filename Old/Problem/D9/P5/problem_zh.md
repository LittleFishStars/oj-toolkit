# 内容

给定一棵以 1 为根的有根树，有 N 个节点和 N-1 条边。输出每个节点的子树大小。

节点 i 的子树大小定义为以 i 为根的子树中包含的节点总数（包括 i 自身）。

提示：可以使用后序遍历（先处理孩子、再处理父亲）来求解子树大小。每个节点的子树大小 = 1 + 所有孩子的子树大小之和。

# 格式

## 输入

第一行一个整数 N（2 ≤ N ≤ 12），表示节点数。

接下来的 N-1 行，每行两个整数 u v（1 ≤ u, v ≤ N），表示 u 是 v 的父亲。

## 输出

输出 N 行，第 i 行输出节点 i 的子树大小。

# 测例

```input1
5
1 2
1 3
2 4
2 5
```

```output1
5
3
1
1
1
```
（节点 1 子树包含全部 5 个节点；节点 2 子树包含 {2,4,5} 共 3 个；其余为叶子）
