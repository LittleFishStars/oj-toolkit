# 内容

给定一棵以 1 为根的有根树，有 N 个节点和 N-1 条边。统计树中叶子节点的数量。

叶子节点是指没有任何孩子节点的节点（度为 0，不考虑父亲）。注意：根节点也可能成为叶子（当 N=1 时），但本题 N ≥ 2。

# 格式

## 输入

第一行一个整数 N（2 ≤ N ≤ 15），表示节点数。

接下来的 N-1 行，每行两个整数 u v（1 ≤ u, v ≤ N），表示 u 是 v 的父亲。

## 输出

输出一个整数，表示叶子节点的数量。

# 测例

```input1
5
1 2
1 3
2 4
2 5
```

```output1
3
```
（节点 3、4、5 是叶子）
