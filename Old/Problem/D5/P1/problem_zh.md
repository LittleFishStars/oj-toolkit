# 内容
输入数字n和n行数据，每行数据由姓名（英文）和年龄（整数）组成。请按年龄升序输出所有数据。若年龄相同则按输入顺序。

# 格式

## 输入
第一行一个整数n，表示接下来有n行数据。
接下来n行，每行包含一个英文字符串（姓名，不含空格）和一个整数（年龄），用空格分隔。

## 输出
按年龄从小到大排序后的n行数据，每行姓名与年龄用空格分隔。若年龄相同则按输入顺序输出。

# 测例

```input1
3
Alice 25
Bob 20
Cathy 22
```
```output1
Bob 20
Cathy 22
Alice 25
```
