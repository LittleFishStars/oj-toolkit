# 内容
输入数字n和n行数据，每行数据由姓名（英文）和年龄（整数）组成。请按姓名首字母A-Z输出（如首字母相同则按第二个字母排序，以此类推），若重名则按年龄升序排序，若姓名和年龄全部相同则按输入顺序。

# 格式

## 输入
第一行一个整数n，表示接下来有n行数据。
接下来n行，每行包含一个英文字符串（姓名，不含空格）和一个整数（年龄），用空格分隔。

## 输出
按规则排序后的n行数据，每行姓名与年龄用空格分隔。排序规则：
1. 按姓名字典序升序（逐字母比较，A在前Z在后）
2. 若姓名相同，按年龄升序
3. 若姓名和年龄都相同，按输入顺序

# 测例

```input1
4
Cathy 20
Alice 22
Alice 20
Bob 25
```
```output1
Alice 20
Alice 22
Bob 25
Cathy 20
```
