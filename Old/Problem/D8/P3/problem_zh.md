# 内容

给定一个无向图的节点数 N 和 M 条边，输出该图的关联矩阵。

关联矩阵是一个 N×M 的矩阵 B，其中 B[i][j] = 1 表示节点 i+1 是第 j+1 条边的端点，B[i][j] = 0 表示不是。边的编号按照输入顺序依次为 1 到 M。

# 格式

## 输入

第一行包含两个整数 N 和 M（1 ≤ N ≤ 8，1 ≤ M ≤ N×(N−1)/2），分别表示节点数和边数。

接下来的 M 行，每行包含两个整数 u 和 v（1 ≤ u, v ≤ N，u ≠ v），按照输入顺序依次编号为第 1, 2, …, M 条边。保证没有重边。

## 输出

输出 N 行，每行 M 个整数（0 或 1），整数之间用空格分隔，表示关联矩阵。

# 测例

```input1
3 3
1 2
2 3
1 3
```

```output1
1 0 1
1 1 0
0 1 1
```
