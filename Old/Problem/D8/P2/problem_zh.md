# 内容

给定一个无向图的节点数 N 和 M 条边，输出该图的邻接表。

邻接表是图的另一种存储方式：对于每个节点，列出与其相连的所有邻居节点。要求每行以 "节点编号: 邻居列表" 的格式输出，邻居列表按编号升序排列。

# 格式

## 输入

第一行包含两个整数 N 和 M（1 ≤ N ≤ 10，0 ≤ M ≤ N×(N−1)/2），分别表示节点数和边数。

接下来的 M 行，每行包含两个整数 u 和 v（1 ≤ u, v ≤ N，u ≠ v），表示一条无向边。保证没有重边。

## 输出

输出 N 行，第 i 行格式为 `i: 邻居列表`，邻居之间用空格分隔，编号从小到大排列。若某节点没有邻居，则冒号后为空（不输出空格）。

# 测例

```input1
4 3
1 2
2 3
2 4
```

```output1
1: 2
2: 1 3 4
3: 2
4: 2
```
