# 内容

给定一个无向图的节点数 N 和 M 条边，输出该图的邻接矩阵。

邻接矩阵是一个 N×N 的矩阵 A，其中 A[i][j] = 1 表示节点 i+1 和节点 j+1 之间有一条边，A[i][j] = 0 表示没有边。由于是无向图，矩阵关于主对角线对称，且主对角线元素始终为 0。

# 格式

## 输入

第一行包含两个整数 N 和 M（1 ≤ N ≤ 10，0 ≤ M ≤ N×(N−1)/2），分别表示节点数和边数，用一个空格隔开。

接下来的 M 行，每行包含两个整数 u 和 v（1 ≤ u, v ≤ N，u ≠ v），表示一条连接节点 u 和节点 v 的无向边。保证没有重边。

## 输出

输出 N 行，每行 N 个整数（0 或 1），整数之间用空格分隔，表示邻接矩阵。

# 测例

```input1
3 2
1 2
2 3
```

```output1
0 1 0
1 0 1
0 1 0
```
