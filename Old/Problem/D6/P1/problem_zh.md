# 内容
你需要模拟一个栈的数据结构，支持 push、pop、查询栈顶和查询栈大小四种操作。

操作编号和格式如下：
- `1 x`：将整数 x 压入栈顶（push）。
- `2`：弹出栈顶元素并输出其值；若栈为空则输出 `Empty`。
- `3`：输出栈顶元素的值（不弹出）；若栈为空则输出 `Empty`。
- `4`：输出当前栈中元素的个数。

# 格式

## 输入
第一行一个整数 n，表示操作次数。
接下来 n 行，每行为一个操作，格式如上所述。

## 输出
对于每次操作 2、3、4，输出一行对应的结果。

# 测例

```input1
8
1 5
1 3
3
2
2
2
1 9
4
```
```output1
3
3
5
Empty
1
```
