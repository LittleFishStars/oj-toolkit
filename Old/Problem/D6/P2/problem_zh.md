# 内容

后缀表达式（逆波兰表达式）是一种不需要括号的表达式表示法，运算符写在操作数之后。例如 `3 4 +` 等价于中缀表达式 `3 + 4`。

给定一个后缀表达式，保证格式合法，请计算并输出其值。

操作数为正整数，运算符包括加（+）、减（-）、乘（*）、除（/）。除法保证能整除。

# 格式

## 输入

第一行一个整数 n，表示表达式中元素（操作数+运算符）的个数。
第二行包含 n 个空格分隔的元素，为操作数（整数）或运算符（`+`、`-`、`*`、`/`）。

## 输出

一个整数，即后缀表达式求值的结果。

# 测例

```input1
7
5 3 2 * + 4 -
```

```output1
7
```
