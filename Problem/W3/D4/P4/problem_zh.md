# 内容

构造一个"七元群"类 `Group`：

- 初始化时把传入的整数对 7 取余保存（记作 n）；
- `__add__`：`(a + b) % 7`；
- `__sub__`：`(a - b) % 7`；
- `__mul__`：`(a * b) % 7`；
- `__truediv__`：乘以另一个元素的逆元，7 是质数，元素 x 的逆元是 x⁵ % 7（因为 x·x⁵ = x⁶ ≡ 1）；
- `__str__`：返回 `[n]` 形式。

输入若干个整数（每行两个或三个），按下面的指令输出结果：

- 一行两个整数 a b，后面没有运算符 → 输出 `a + b` 的结果；
- 一行三个：`a + b` / `a - b` / `a * b` / `a / b`（运算符在中间，用空格分开）→ 输出对应运算结果。

数据保证除法时 b 不是 7 的倍数。

# 格式

## 输入

第一行一个整数 m（1 ≤ m ≤ 20），表示接下来有 m 行运算。

接下来 m 行，每行 `a b` 或 `a op b`，用空格分开（0 ≤ a, b ≤ 1000）。

## 输出

共 m 行，每行是运算结果的 `[n]` 形式。

# 测例

```input1
2
1 6
3 * 5
```
```output1
[0]
[1]
```

```input2
2
3 - 5
8 / 2
```
```output2
[5]
[4]
```
