# 内容

定义分数类 `Frac`，用分子 p、分母 q 初始化（q > 0），实现：

- `__add__`：两个分数相加，结果要**约分到最简**，并保持分母为正；
- `__str__`：返回 `p/q` 形式的字符串。

输入两行，每行两个正整数（分子 分母），输出两个分数之和的最简形式。

例如 1/6 + 1/3 = 1/2，输出 `1/2`；2/4 + 2/4 = 1，输出 `1/1`。

提示：p1/q1 + p2/q2 = (p1·q2 + p2·q1) / (q1·q2)，再用辗转相除求最大公因数约分。

# 格式

## 输入

共两行，每行两个正整数 p q，用空格分开（1 ≤ p ≤ 1000，1 ≤ q ≤ 1000）。

## 输出

一行，形如 `p/q` 的最简分数（分母为 1 也要写成 `x/1`）。

# 测例

```input1
1 6
1 3
```
```output1
1/2
```

```input2
2 4
2 4
```
```output2
1/1
```
