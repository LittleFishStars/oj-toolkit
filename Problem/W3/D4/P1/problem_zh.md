# 内容

定义向量类 `Vec`，用两个整数 x、y 初始化，实现：

- `__add__`：两个向量相加，结果是各分量分别相加的新向量；
- `__str__`：返回 `(x,y)` 形式的字符串。

输入两行，每行两个整数（各一个向量的 x y），输出相加后的向量。

# 格式

## 输入

共两行，每行两个整数，用空格分开（-1000 ≤ 各分量 ≤ 1000）。

## 输出

一行，形如 `(3,5)`（逗号前后没有空格）。

# 测例

```input1
1 2
3 4
```
```output1
(4,6)
```

```input2
-1 1
1 -1
```
```output2
(0,0)
```
