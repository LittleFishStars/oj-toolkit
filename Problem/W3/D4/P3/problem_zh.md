# 内容

定义学生类 `Student`，用姓名和成绩初始化，实现：

- `__lt__`：比较两个学生时，成绩低的算小；成绩相同时，姓名字典序小的算小；
- `__str__`：返回 `姓名 成绩` 形式。

输入 n 个学生的姓名和成绩，用 `sorted(students)` 排序后按顺序输出每个学生的 `__str__` 结果。

提示：实现了 `__lt__` 之后，`sorted` 不需要 `key` 参数就能自动排序。

# 格式

## 输入

第一行一个整数 n（1 ≤ n ≤ 100）。

接下来 n 行，每行一个姓名和一个整数成绩，用空格分开（姓名是 1 ~ 10 个小写字母，0 ≤ 成绩 ≤ 100）。

## 输出

共 n 行，每行 `姓名 成绩`。

# 测例

```input1
3
tom 90
amy 95
bob 60
```
```output1
bob 60
tom 90
amy 95
```

```input2
2
amy 80
bob 80
```
```output2
amy 80
bob 80
```
