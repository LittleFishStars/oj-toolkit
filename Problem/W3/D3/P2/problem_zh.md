# 内容

定义一个基类 `Shape`，提供方法 `area()`（基类里返回 0）。

再定义两个子类：

- `Square`：用边长初始化，`area()` 返回边长的平方；
- `Circle`：用半径初始化，`area()` 返回 π r²（π 取 3.14）。

输入一个形状类型和一个整数参数，输出它的面积（保留 2 位小数）。若类型是 `square` 参数为边长，若是 `circle` 参数为半径。

# 格式

## 输入

一行一个类型和一个整数，用空格分开（类型是 `square` 或 `circle`，参数 1 ≤ x ≤ 1000）。

## 输出

一行一个数，面积保留 2 位小数。

# 测例

```input1
square 5
```
```output1
25.00
```

```input2
circle 2
```
```output2
12.56
```
