# 内容

输入一行英文句子（只含小写字母和空格），统计每个单词出现的次数，按下面的顺序输出：

1. 次数从多到少；
2. 次数相同时，单词字典序从小到大。

每行输出 `单词 次数`。

提示：`sorted` 的 `key` 可以返回 `(-次数, 单词)`，一次把两个条件都排好。

# 格式

## 输入

一行英文句子，单词之间用一个或多个空格分开（总长度 1 ~ 200，只含小写字母和空格）。

## 输出

若干行，每行 `单词 次数`。

# 测例

```input1
the cat and the dog and the bird
```
```output1
the 3
and 2
bird 1
cat 1
dog 1
```

```input2
a a b
```
```output2
a 2
b 1
```

# 限制

Python: 100ms, 10MB
