# 内容

输入两个矩阵 A（n×k）和 B（k×m），输出它们的乘积 C = A×B（n×m）。

矩阵用二维列表表示，乘法写成函数 `matmul(A, B)`。

提示：`C[i][j] = A[i][0]·B[0][j] + A[i][1]·B[1][j] + ... + A[i][k-1]·B[k-1][j]`，用三层 `for` 循环即可。

# 格式

## 输入

共五行：

- 第一行三个整数 n k m（1 ≤ n, k, m ≤ 5）；
- 接下来 n 行，每行 k 个整数，是矩阵 A 的一行；
- 接下来 k 行，每行 m 个整数，是矩阵 B 的一行。

矩阵元素都是 0 ~ 100 的整数，相邻整数用空格分开。

## 输出

共 n 行，每行 m 个整数，是乘积矩阵 C 的一行，用空格分开。

# 测例

```input1
2 2 2
1 2
3 4
5 6
7 8
```
```output1
19 22
43 50
```

```input2
1 3 1
1 2 3
4
5
6
```
```output2
32
```
