# 内容

输入 n 个学生的姓名和成绩，输出四项统计：

- 人数、平均分（保留 2 位小数）；
- 最高分学生的姓名（并列取最先出现的）；
- 及格率（成绩 ≥ 60 的人数占比，保留 1 位小数百分比，例如 66.7%）。

要求：定义一个 `Analyzer` 类，把统计逻辑写成方法。

# 格式

## 输入

第一行一个整数 n（1 ≤ n ≤ 100）。

接下来 n 行，每行一个姓名和一个整数成绩，用空格分开（姓名 1 ~ 10 个小写字母，0 ≤ 成绩 ≤ 100）。

## 输出

共三行：

- 第一行：`人数 平均分`，用空格分开，平均分保留 2 位小数；
- 第二行：最高分姓名；
- 第三行：及格率，保留 1 位小数并带 `%`。

# 测例

```input1
3
tom 90
amy 70
bob 50
```
```output1
3 70.00
tom
66.7%
```

```input2
1
zoe 59
```
```output2
1 59.00
zoe
0.0%
```
