# 内容

编写几个小函数，再由一个主函数按指令调用：

- `add(a, b)` → a + b
- `sub(a, b)` → a - b
- `mul(a, b)` → a * b
- `div(a, b)` → a / b（保留 2 位小数）

输入若干行指令，每行形如 `add 3 4`，输出每行的计算结果（各占一行）。

提示：可以把四个函数放进字典 `ops = {"add": add, "sub": sub, ...}`，再 `ops[名字](x, y)` 调用。

# 格式

## 输入

第一行一个整数 m（1 ≤ m ≤ 20）。

接下来 m 行，每行 `操作 整数 整数`，操作是 `add`、`sub`、`mul`、`div` 之一，两个整数 0 ≤ x, y ≤ 1000。数据保证 `div` 时 y 不为 0。

## 输出

共 m 行，`add`/`sub`/`mul` 输出整数结果，`div` 输出保留 2 位小数的结果。

# 测例

```input1
3
add 3 4
div 7 2
mul 2 5
```
```output1
7
3.50
10
```

```input2
1
sub 5 9
```
```output2
-4
```
