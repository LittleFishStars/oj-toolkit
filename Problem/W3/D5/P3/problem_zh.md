# 内容

定义一个日期类 `Date`，用月 m 和日 d 初始化（1 ≤ m ≤ 12，1 ≤ d ≤ 30）。

- `__add__`：日期加上若干天，返回新日期。为了简单，**每个月固定 30 天**，月份循环 1~12；
- `__str__`：返回 `m/d` 形式（不含前导零）。

输入一个日期和要加的天数 k，输出加上 k 天之后的日期。

例如 12/25 加 10 天 = 1/5。

提示：把日期换算成"从 1/1 起第几天"再加法取模，也可以直接展开成总天数再转回。

# 格式

## 输入

一行三个整数 m d k，用空格分开（1 ≤ m ≤ 12，1 ≤ d ≤ 30，0 ≤ k ≤ 10000）。

## 输出

一行，形如 `m/d` 的新日期。

# 测例

```input1
12 25 10
```
```output1
1/5
```

```input2
1 1 0
```
```output2
1/1
```

# 限制
