# 内容

定义一个等差数列类 `Seq`，用首项 a、公差 d、长度 n 初始化（n ≥ 1），实现：

- `__len__`：返回长度 n；
- `__getitem__(i)`：返回第 i 项（下标从 0 开始，0 ≤ i < n）；
- `__iter__`：让对象可以用 `for` 遍历全部项；
- `__str__`：返回所有项用空格连接。

输入首项、公差和长度，以及若干下标查询，输出：

1. 第一行：整个序列；
2. 之后每个查询一行：对应下标的值。

# 格式

## 输入

第一行三个整数 a d n，用空格分开（-1000 ≤ a, d ≤ 1000，1 ≤ n ≤ 1000）。

第二行一个整数 q（0 ≤ q ≤ 20），表示查询次数。

接下来 q 行，每行一个整数 i（0 ≤ i < n）。

## 输出

共 q+1 行：第一行是整个序列（用空格分开），之后每行一个查询结果。

# 测例

```input1
1 2 4
2
0
3
```
```output1
1 3 5 7
1
7
```

```input2
5 0 1
0
```
```output2
5
```
