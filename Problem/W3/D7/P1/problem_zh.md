# 内容

用类实现一个支持运算符优先级和括号的整数表达式求值器（只用 `+ - * /` 和圆括号，操作数是非负整数）。

例如 `2+3*4` = 14，`(2+3)*4` = 20，`10/4` 按整数除法输出 2。

输入一个表达式，输出它的值（所有中间结果都按整数处理，除法向下取整）。

提示：可以先把中缀表达式转成后缀（调度场算法），也可以用一个"先算乘除、再算加减"的循环反复化简括号。本题不限制写法。

# 格式

## 输入

一行一个表达式（长度 1 ~ 100），只含数字、`+ - * /` 和圆括号，没有空格。

## 输出

一行一个整数，表达式的值。

# 测例

```input1
2+3*4
```
```output1
14
```

```input2
(2+3)*4
```
```output2
20
```

# 限制

Python: 100ms, 10MB
