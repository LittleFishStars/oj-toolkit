# 内容

定义学生类 `Student`（姓名 + 成绩），再定义一个班级类 `Classroom`：

- 用学生列表初始化；
- `best()`：返回分数最高的学生姓名（并列时取最先出现的那位）；
- `average()`：返回全班平均分（浮点数）；
- `above()`：返回成绩高于平均分的人数。

输入 n 个学生的姓名和成绩，输出上面三项：最高分姓名、平均分（保留 2 位小数）、高于平均分的人数，各占一行。

提示：先在循环里创建 n 个 `Student` 对象放进列表，再把这些对象交给 `Classroom`。

# 格式

## 输入

第一行一个整数 n（1 ≤ n ≤ 100）。

接下来 n 行，每行一个姓名和一个整数成绩，用空格分开（姓名是 1 ~ 10 个小写字母，0 ≤ 成绩 ≤ 100）。

## 输出

共三行：最高分姓名、平均分（保留 2 位小数）、高于平均分的人数。

# 测例

```input1
3
tom 90
amy 70
bob 80
```
```output1
tom
80.00
1
```

```input2
2
ann 100
ben 100
```
```output2
ann
100.00
0
```
