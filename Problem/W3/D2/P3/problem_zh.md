# 内容

定义一个三角形类 `Triangle`，用三条边初始化，提供两个方法：

- `perimeter()`：返回周长；
- `area()`：用海伦公式返回面积：半周长 p = 周长 / 2，面积 = √(p(p-a)(p-b)(p-c))。

输入三条边（整数），输出周长（整数）和面积（保留 2 位小数），各占一行。数据保证三条边能构成三角形。

提示：开平方可以用 `** 0.5`，`pow(x, 0.5)` 也可以。

# 格式

## 输入

一行三个整数 a b c，用空格分开（1 ≤ a, b, c ≤ 1000，保证能构成三角形）。

## 输出

共两行：第一行周长，第二行面积，保留 2 位小数。

# 测例

```input1
3 4 5
```
```output1
12
6.00
```

```input2
2 2 2
```
```output2
6
1.73
```
