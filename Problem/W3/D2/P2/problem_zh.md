# 内容

定义一个学生类 `Student`，用姓名和成绩初始化，提供两个方法：

- `level()`：返回成绩等级——90 分及以上 `A`，80 分及以上 `B`，70 分及以上 `C`，60 分及以上 `D`，否则 `E`；
- `card()`：返回一行名片文字，格式为 `姓名:成绩 等级X`。

输入姓名和成绩，输出名片那一行。

# 格式

## 输入

一行一个姓名和一个整数成绩，用空格分开（姓名是 1 ~ 10 个小写字母，0 ≤ 成绩 ≤ 100）。

## 输出

一行，格式为 `姓名:成绩 等级X`。

# 测例

```input1
amy 85
```
```output1
amy:85 等级B
```

```input2
bob 59
```
```output2
bob:59 等级E
```

# 限制

Python: 100ms, 10MB
