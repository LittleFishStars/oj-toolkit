# 内容

输入一行整数，对每个数按下面的规则处理，并按原顺序输出处理后的结果（用空格分开）：

- 偶数 → 它的平方
- 奇数 → 它的 3 倍加 1

提示：`map` 可以一行完成映射：`map(lambda x: ..., nums)`，再用 `print(*arr)` 或 `join` 输出。

# 格式

## 输入

一行若干个整数，用空格分开（个数 1 ~ 20，每个数的绝对值 ≤ 1000）。

## 输出

一行若干个整数，是每个数处理后的结果，用空格分开。

# 测例

```input1
1 2 3 4
```
```output1
4 4 10 16
```

```input2
5
```
```output2
16
```

# 限制
