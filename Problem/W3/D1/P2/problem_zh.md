# 内容

定义一个函数 `total(*args)`，它把收到的所有参数加起来返回。

- 不传参数时返回 0；
- 输入一行整数，把它们全部传给这个函数，输出返回的和。

提示：`def total(*args)` 里的 `*args` 会把任意多个参数收进一个元组，用 `for` 遍历求和即可。

# 格式

## 输入

一行若干个整数，用空格分开（个数 0 ~ 20，每个数的绝对值 ≤ 1000）。若一行没有任何内容，表示没有参数。

## 输出

一行一个整数，表示所有数的和（没有数时为 0）。

# 测例

```input1
1 2 3
```
```output1
6
```

```input2
0
```
```output2
0
```
