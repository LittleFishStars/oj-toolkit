# 内容

定义分段函数 f(x)：

| 区间 | 取值 |
| --- | --- |
| x < 0 | -x |
| 0 ≤ x < 10 | x * x |
| x ≥ 10 | x + 100 |

输入一个整数 x，输出 f(x)。

提示：用 `def` 把 f 定义成一个函数，函数体里用 if/elif/else 分三段。

# 格式

## 输入

一行一个整数 x（-1000 ≤ x ≤ 1000）。

## 输出

一行一个整数，表示 f(x)。

# 测例

```input1
-3
```
```output1
3
```

```input2
5
```
```output2
25
```

```input3
12
```
```output3
112
```
