# 内容

输入一行整数，按下面的优先级重新排序后输出：

1. 先按各位数字之和从小到大；
2. 数字之和相同时，按数值本身从小到大。

例如 12（和 3）排在 21（和 3）前面，25（和 7）排在 12 后面。

提示：`sorted(nums, key=...)` 的 key 可以是一个函数；想同时按两个条件比较，让函数返回元组 `(各位数字之和, 原数)`。

# 格式

## 输入

一行若干个整数，用空格分开（个数 1 ~ 20，每个数是 0 ~ 1000 的整数）。

## 输出

一行若干整数，按上面的优先级排好序，用空格分开。

# 测例

```input1
25 12 7 21
```
```output1
12 21 7 25
```

```input2
9 8 7
```
```output2
7 8 9
```

# 限制
