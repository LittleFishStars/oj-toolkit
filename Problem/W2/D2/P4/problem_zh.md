# 内容

输入一个整数 n，打印一个高为 n 的等腰三角形，用 `#` 拼成。

第 i 行由 n - i 个空格和 2 × i - 1 个 `#` 组成，例如 n = 3 时：

```
  #
 ###
#####
```

提示：空格和 `#` 都可以用字符串乘法生成，如 `' ' * 2`、`'#' * 3`；外层循环控制第几行，`for` 和 `while` 都可以。

# 格式

## 输入

一行一个整数 n（1 ≤ n ≤ 20）。

## 输出

共 n 行，组成一个底边长为 2n-1 的等腰三角形（行末不要多出空格）。

# 测例

```input1
3
```
```output1
  #
 ###
#####
```

```input2
1
```
```output2
#
```

# 限制

Python: 100ms, 10MB
