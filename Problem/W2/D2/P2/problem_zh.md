# 内容

输入一个非负整数 n，把它倒过来读，输出得到的新整数。

例如 1234 倒过来是 4321；1200 倒过来读是 0021，作为整数输出 21；0 倒过来还是 0。

提示：`while` 循环里每次取出 n 的末位数字，拼到结果变量的后面（`结果 * 10 + 末位`），再把 n 去掉末位。

# 格式

## 输入

一行一个整数 n（0 ≤ n ≤ 1000000000，通常写法不含前导零）。

## 输出

一行一个整数，表示 n 的数字反转结果（不含前导零）。

# 测例

```input1
1234
```
```output1
4321
```

```input2
1200
```
```output2
21
```

```input3
0
```
```output3
0
```

# 限制
