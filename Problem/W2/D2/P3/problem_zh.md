# 内容

斐波那契数列的前两项都是 1，从第 3 项开始，每一项都等于它前面两项的和：

1, 1, 2, 3, 5, 8, 13, 21, ...

输入一个整数 n，输出这个数列的前 n 项，每项占一行。

提示：用两个变量保存当前项和下一项，循环一次就把它们往后推一项。

# 格式

## 输入

一行一个整数 n（1 ≤ n ≤ 30）。

## 输出

共 n 行，每行一个整数，依次为数列的前 n 项。

# 测例

```input1
6
```
```output1
1
1
2
3
5
8
```

```input2
1
```
```output2
1
```

# 限制
