# 内容

质数是大于 1 且只能被 1 和它本身整除的整数（2、3、5、7、11 … 都是质数，4、6、8、9 不是）。

输入一个整数 n，如果 n 是质数输出 1，否则输出 0。

提示：用 `for` 从 2 试除到 n-1，能整除就 `break`。`for` 可以配 `else`：只有循环没有被 `break` 打断时，`else` 才会执行——正好对应「没找到因数，是质数」。

# 格式

## 输入

一行一个整数 n（2 ≤ n ≤ 100000）。

## 输出

一行，质数输出 1，否则输出 0。

# 测例

```input1
7
```
```output1
1
```

```input2
4
```
```output2
0
```

# 限制

Python: 100ms, 10MB
