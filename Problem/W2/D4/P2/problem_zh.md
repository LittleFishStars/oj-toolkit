# 内容

输入两个整数 a 和 b（a ≤ b），输出闭区间 [a, b] 里质数的个数。

提示：外层 `for` 枚举区间里的每个数，内层 `for` 判断它是不是质数；判断可以用 `for...else`，也可以用一个标记变量。

# 格式

## 输入

一行两个整数 a b，用空格分开（2 ≤ a ≤ b ≤ 1000）。

## 输出

一行一个整数，表示 [a, b] 中质数的个数。

# 测例

```input1
2 10
```
```output1
4
```

```input2
4 4
```
```output2
0
```

# 限制

Python: 100ms, 10MB
