# 内容

输入一个大于 1 的整数 n，把 n 分解成质数相乘的形式，按质数从小到大输出这个乘法式子。

例如 12 = 2 × 2 × 3，输出 `2*2*3`；97 是质数，输出 `97`。

提示：从最小的质数 2 开始试，能整除就一直除下去（内层 `while`），除不动了再把试除的数加 1（外层 `while`）。

# 格式

## 输入

一行一个整数 n（2 ≤ n ≤ 100000）。

## 输出

一行，n 的质因数从小到大用 `*` 连接。

# 测例

```input1
12
```
```output1
2*2*3
```

```input2
97
```
```output2
97
```

```input3
100
```
```output3
2*2*5*5
```
