# 内容

输入一个整数 n，输出 1²、2²、…、n²，用空格分开，全部写在同一行。

提示：列表推导式 `[x * x for x in range(1, n + 1)]` 可以一行生成整个列表；`' '.join(...)` 要求元素是字符串，记得先转成字符串。

# 格式

## 输入

一行一个整数 n（1 ≤ n ≤ 100）。

## 输出

一行 n 个整数，依次是 1 到 n 的平方，用空格分开。

# 测例

```input1
5
```
```output1
1 4 9 16 25
```

```input2
1
```
```output2
1
```

# 限制

Python: 100ms, 10MB
