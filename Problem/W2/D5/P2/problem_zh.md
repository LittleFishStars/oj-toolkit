# 内容

输入一行若干个整数，按原来的顺序输出其中的偶数，用空格分开。

数据保证至少有一个偶数。

提示：列表推导式里可以带 `if`：`[x for x in nums if x % 2 == 0]` 只保留符合条件的元素。

# 格式

## 输入

一行若干个整数，用空格分开（个数 1 ~ 20，每个数的绝对值 ≤ 1000），其中至少有一个偶数。

## 输出

一行，按原顺序输出所有偶数，用空格分开。

# 测例

```input1
5 2 7 8 3
```
```output1
2 8
```

```input2
2 4 6
```
```output2
2 4 6
```

# 限制

Python: 100ms, 10MB
