# 内容

输入一个整数 n，输出 1 到 n 每个数以及它的平方，格式为 `数字:平方`，各项之间用一个空格分开。

例如 n = 3 时输出 `1:1 2:4 3:9`。

提示：字典推导式 `{x: x * x for x in range(1, n + 1)}` 可以一行建好这张表，再用 `squares[x]` 取值。

# 格式

## 输入

一行一个整数 n（1 ≤ n ≤ 20）。

## 输出

一行 n 项，第 k 项是 `k:k*k`，用空格分开，按 k 从小到大排列。

# 测例

```input1
3
```
```output1
1:1 2:4 3:9
```

```input2
1
```
```output2
1:1
```
