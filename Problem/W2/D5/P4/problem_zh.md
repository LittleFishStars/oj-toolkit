# 内容

输入一个整数 n，输出这样一个式子：

- 第 1 项是 `+x^1/1`，第 2 项是 `-x^2/2`，第 3 项是 `+x^3/3` ……
- 也就是 k 为奇数时符号是 `+`，k 为偶数时符号是 `-`。

n = 3 时输出 `+x^1/1-x^2/2+x^3/3`。

提示：列表推导式里可以用条件表达式，`'+' if k % 2 else '-'` 根据 k 的奇偶挑符号。

# 格式

## 输入

一行一个整数 n（1 ≤ n ≤ 20）。

## 输出

一行一个字符串，从 k = 1 拼到 k = n，中间没有空格。

# 测例

```input1
3
```
```output1
+x^1/1-x^2/2+x^3/3
```

```input2
1
```
```output2
+x^1/1
```
