# 内容

输入一行文本，分别统计其中的大写字母、小写字母、数字和其他字符的个数。

提示：用 `for` 逐个取出字符，用比较运算判断范围，比如 `'A' <= ch <= 'Z'` 是大写字母、`'a' <= ch <= 'z'` 是小写字母、`'0' <= ch <= '9'` 是数字，剩下的都算其他字符（空格、标点等）。

# 格式

## 输入

一行文本（长度 1 ~ 100，只含字母、数字、空格和标点，首尾不是空格）。

## 输出

一行四个整数，依次是大写字母、小写字母、数字、其他字符的个数，用空格分开。

# 测例

```input1
Hello World 123!
```
```output1
2 8 3 3
```

```input2
abc
```
```output2
0 3 0 0
```

# 限制

Python: 100ms, 10MB
