# 内容

输入一个班 n 个学生的姓名和成绩，输出：

- 分数最高的学生姓名（如果有并列，输出最先出现的那位）；
- 全班平均分，保留 2 位小数；
- 分数高于平均分的人数。

# 格式

## 输入

第一行一个整数 n（1 ≤ n ≤ 100）。

接下来 n 行，每行一个姓名和一个整数成绩，用空格分开（姓名是 1 ~ 10 个小写字母，0 ≤ 成绩 ≤ 100）。

## 输出

共三行：

- 第一行：最高分学生的姓名；
- 第二行：平均分，保留 2 位小数；
- 第三行：高于平均分的人数。

# 测例

```input1
3
tom 90
amy 70
bob 80
```
```output1
tom
80.00
1
```

```input2
2
ann 100
ben 100
```
```output2
ann
100.00
0
```
