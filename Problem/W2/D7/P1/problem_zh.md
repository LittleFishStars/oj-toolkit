# 内容

回文数是指正着读和倒着读都一样的整数，例如 121、7、1001 都是回文数，1234 不是。

输入一个非负整数 n，是回文数输出 `Yes`，否则输出 `No`。

提示：把数字当成字符串，`s[::-1]` 就是倒过来读的结果，比较一下即可。

# 格式

## 输入

一行一个整数 n（0 ≤ n ≤ 1000000000）。

## 输出

一行，`Yes` 或 `No`。

# 测例

```input1
121
```
```output1
Yes
```

```input2
1234
```
```output2
No
```

# 限制

Python: 100ms, 10MB
