# 内容

一行一个整数地读入，读到 0 就停止，输出 0 之前所有整数的和（0 本身不算）。

提示：可以用 `while True` 配合 `break`——每轮读入一个数，等于 0 就 `break` 跳出循环。

# 格式

## 输入

若干行，每行一个整数（绝对值不超过 1000），最后一行一定是 0。

## 输出

一行一个整数，表示 0 之前所有整数的和（若第一行就是 0，输出 0）。

# 测例

```input1
5
3
0
```
```output1
8
```

```input2
7
0
```
```output2
7
```

```input3
0
```
```output3
0
```
