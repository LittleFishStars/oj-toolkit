# 内容

输入一个长度为 n 的整数序列和一个目标值 x，输出 x 在这个序列中第一次出现的位置（位置从 1 开始编号）；如果序列里没有 x，输出 -1。

提示：用 `for` 配合下标从左往右找，找到就把位置记下来并 `break`；循环结束后再统一输出。

# 格式

## 输入

共三行：

- 第一行一个整数 n（1 ≤ n ≤ 100）；
- 第二行 n 个整数，用空格分开（每个数的绝对值 ≤ 1000）；
- 第三行一个整数 x，目标值。

## 输出

一行一个整数：x 第一次出现的位置，找不到输出 -1。

# 测例

```input1
5
3 7 1 9 7
7
```
```output1
2
```

```input2
5
3 7 1 9 7
5
```
```output2
-1
```

# 限制
