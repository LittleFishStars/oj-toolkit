# 内容

输入一个大于 1 的整数 n，输出它除 1 以外最小的那个因数。

如果 n 是质数（只能被 1 和它本身整除），就输出 n 自己。

提示：`for` 从小往大试除，第一个能整除 n 的数就是答案，找到后立刻 `break` 结束循环。

# 格式

## 输入

一行一个整数 n（2 ≤ n ≤ 100000）。

## 输出

一行一个整数，表示 n 的最小因数（n 为质数时就是 n）。

# 测例

```input1
9
```
```output1
3
```

```input2
17
```
```output2
17
```

# 限制

Python: 100ms, 10MB
