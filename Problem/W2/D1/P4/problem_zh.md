# 内容

输入一个整数 n，输出九九乘法表的前 n 行（下三角形式）。

第 i 行依次输出 i×1、i×2、…、i×i 的算式，每个算式形如 `3*2=6`，算式之间用一个空格分开。

提示：外层循环控制第几行，内层循环控制这一行有几个算式。

# 格式

## 输入

一行一个整数 n（1 ≤ n ≤ 9）。

## 输出

共 n 行，第 i 行有 i 个算式，用空格分开。

# 测例

```input1
3
```
```output1
1*1=1
2*1=2 2*2=4
3*1=3 3*2=6 3*3=9
```

```input2
1
```
```output2
1*1=1
```
