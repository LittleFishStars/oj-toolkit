# 内容

一个 k 位数，如果它各位数字的 k 次方之和恰好等于它本身，就叫水仙花数。

例如 153 是 3 位数，1³ + 5³ + 3³ = 153，所以它是水仙花数；9474 是 4 位数，9⁴ + 4⁴ + 7⁴ + 4⁴ = 9474，也是水仙花数。一位数 1 ~ 9 都满足（k = 1 时 d¹ = d）。

输入一个正整数 n，如果它是水仙花数输出 1，否则输出 0。

提示：先用一个 `while` 循环数出 n 有几位，再用 `while` 循环把各位数字取出来求幂、累加。

# 格式

## 输入

一行一个整数 n（1 ≤ n ≤ 1000000）。

## 输出

一行，水仙花数输出 1，否则输出 0。

# 测例

```input1
153
```
```output1
1
```

```input2
100
```
```output2
0
```

# 限制
