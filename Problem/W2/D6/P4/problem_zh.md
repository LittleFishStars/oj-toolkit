# 内容

对任意一个四位整数（四个数字不完全相同）反复做这样的操作：

1. 把它的四个数字按从大到小排成一个数（大数）；
2. 再按从小到大排成一个数（小数，允许以 0 开头，比如 0999 就是 999）；
3. 用大数减小数，得到新的四位数。

这样一直做下去，最后一定会停在 6174，这个数被称为数字黑洞。

输入一个四位数 n，输出从 n 出发需要操作多少次才能得到 6174（如果输入就是 6174，输出 0）。数据保证 n 的四个数字不完全相同。

提示：用 `//` 和 `%` 取出四个数字放进列表，用 `sorted` 排序后重新拼成大数和小数。

# 格式

## 输入

一行一个整数 n（1000 ≤ n ≤ 9999，四个数字不完全相同）。

## 输出

一行一个整数，表示得到 6174 所需的操作次数。

# 测例

```input1
3524
```
```output1
3
```

```input2
6174
```
```output2
0
```

# 限制
