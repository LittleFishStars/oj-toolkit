# 内容

输入一个班 n 个学生的成绩，输出最高分和最低分、全班平均分（保留 2 位小数）以及及格（分数 ≥ 60）的人数。

# 格式

## 输入

共两行：

- 第一行一个整数 n（1 ≤ n ≤ 100）；
- 第二行 n 个整数成绩，用空格分开（0 ≤ 成绩 ≤ 100）。

## 输出

共三行：

- 第一行两个整数：最高分和最低分，用空格分开；
- 第二行一个数：平均分，保留 2 位小数；
- 第三行一个整数：及格人数。

# 测例

```input1
5
88 59 72 90 45
```
```output1
90 45
70.80
3
```

```input2
1
59
```
```output2
59 59
59.00
0
```

# 限制

Python: 100ms, 10MB
