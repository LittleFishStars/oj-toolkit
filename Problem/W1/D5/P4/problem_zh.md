# 内容

建立一本电话簿：先录入 n 个联系人的姓名和电话，再查询 m 个名字。用字典存储电话簿，查询时判断名字是否存在。

# 格式

## 输入

第一行一个整数 n（1 ≤ n ≤ 20）。
接下来 n 行，每行一个姓名 name 和电话 phone（均为不含空格的字符串，姓名长度 ≤ 10，电话为数字串）。
接下来一行一个整数 m（1 ≤ m ≤ 20）。
接下来 m 行，每行一个要查询的姓名。

## 输出

m 行，对每个查询：姓名存在输出对应的电话，否则输出 `Not Found`。

# 测例

```input1
3
Alice 13800000001
Bob 13800000002
Cindy 13800000003
2
Bob
David
```
```output1
13800000002
Not Found
```
