# 内容

输入两个整数和一个运算符（`+`、`-`、`*`、`/` 之一），计算对应的结果。

- 加减乘输出整数结果；
- 除法输出商，保留 2 位小数；
- 除数为 0 时输出 `Error`。

# 格式

## 输入

一行，格式为 `a op b`：两个整数 a、b（0 ≤ a, b ≤ 100）和运算符 op，用空格分开。

## 输出

一行：
- `+` `-` `*` 输出整数结果；
- `/` 当 b ≠ 0 时输出保留 2 位小数的结果，b = 0 时输出 `Error`。

# 测例

```input1
3 + 5
```
```output1
8
```

```input2
7 / 2
```
```output2
3.50
```

```input3
5 / 0
```
```output3
Error
```

# 限制
