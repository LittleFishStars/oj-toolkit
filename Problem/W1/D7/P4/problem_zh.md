# 内容

公园门票每张 10 元。优惠规则（优惠不叠加，按最便宜的执行）：

- 年龄小于 6 岁 **或** 不小于 60 岁：免费（0 元）；
- 否则，如果是学生（输入 1 表示是）：半价 5 元；
- 否则，如果是会员（输入 1 表示是）：九折 9 元；
- 其余：原价 10 元。

输入游客的年龄、是否学生、是否会员，输出应付票价。

# 格式

## 输入

一行三个数：整数 age（1 ≤ age ≤ 100）、整数 student（0 或 1）、整数 member（0 或 1），空格分开。

## 输出

一行一个整数，应付票价（元）。

# 测例

```input1
5 0 0
```
```output1
0
```

```input2
30 1 0
```
```output2
5
```

```input3
30 0 0
```
```output3
10
```
