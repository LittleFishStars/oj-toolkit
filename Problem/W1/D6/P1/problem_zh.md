# 内容

两个玩家玩石头剪刀布。用数字表示手势：`0` 石头、`1` 剪刀、`2` 布。

规则：石头赢剪刀，剪刀赢布，布赢石头。

# 格式

## 输入

一行两个整数 a b（0 ≤ a, b ≤ 2），分别表示玩家 1 和玩家 2 的手势。

## 输出

一行：
- 玩家 1 获胜输出 `Player 1 wins`
- 玩家 2 获胜输出 `Player 2 wins`
- 平局输出 `Draw`

# 测例

```input1
0 1
```
```output1
Player 1 wins
```

```input2
2 2
```
```output2
Draw
```
