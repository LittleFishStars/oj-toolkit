# 内容

输入一行字符，统计 5 个元音字母 a、e、i、o、u 各出现了多少次。

提示：字符串的 `count` 方法可以直接统计子串出现次数，如 `s.count("a")`。

# 格式

## 输入

一行一个字符串 s（1 ≤ 长度 ≤ 100，仅含小写字母和其他 ASCII 可见字符）。

## 输出

一行，格式为 `a:x e:x i:x o:x u:x`，x 为对应元音字母的出现次数。

# 测例

```input1
hello world
```
```output1
a:0 e:1 i:0 o:2 u:0
```

# 限制

Python: 100ms, 10MB
