# 内容

快递公司计费规则：

- 首重 1 公斤（含）8 元；
- 超过 1 公斤的部分，每公斤（不足 1 公斤按 1 公斤算）加收 4 元；
- 加急件在上述基础上另加 5 元。

输入包裹重量（整数克）和是否加急，计算运费。

# 格式

## 输入

一行两个数：整数 w（1 ≤ w ≤ 100000，单位克）和整数 u（1 表示加急，0 表示不加急），空格分开。

## 输出

一行一个整数，运费（元）。

# 测例

```input1
800 0
```
```output1
8
```

```input2
2500 1
```
```output2
21
```

（2500 克 = 首重 8 元 + 续重 2 公斤 8 元 + 加急 5 元）

# 限制

Python: 100ms, 10MB
