# 内容

输入年、月、日，判断这是一个真实存在的日期吗？规则：

- 月份 1 ~ 12；
- 1、3、5、7、8、10、12 月有 31 天；4、6、9、11 月有 30 天；
- 2 月：闰年 29 天，平年 28 天（闰年：能被 4 整除但不能被 100 整除，或能被 400 整除）。

# 格式

## 输入

一行三个整数 y m d，用空格分开（1 ≤ y ≤ 3000）。

## 输出

合法输出 `Yes`，不合法输出 `No`。

# 测例

```input1
2024 2 29
```
```output1
Yes
```

```input2
2023 2 29
```
```output2
No
```

```input3
2023 13 1
```
```output3
No
```
