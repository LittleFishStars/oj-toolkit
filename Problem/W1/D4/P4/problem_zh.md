# 内容

输入体重（公斤）和身高（米），计算 BMI = 体重 ÷ 身高的平方，并按中国标准分级：

- BMI < 18.5：偏瘦
- 18.5 ≤ BMI < 24：正常
- 24 ≤ BMI < 28：偏胖
- BMI ≥ 28：肥胖

输出 BMI（保留 1 位小数）和对应的分级。

# 格式

## 输入

一行两个数 w h，用空格分开：体重 w（30 ≤ w ≤ 150，整数）、身高 h（1.2 ≤ h ≤ 2.2，可能带小数）。

## 输出

一行：先输出 BMI 保留 1 位小数，空一格，再输出分级。例如 `22.5 正常`。

# 测例

```input1
65 1.70
```
```output1
22.5 正常
```

```input2
45 1.60
```
```output2
17.6 偏瘦
```
