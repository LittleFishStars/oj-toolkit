# 内容

输入三条线段的长度，判断它们能组成什么三角形：

- 任意两边之和大于第三边才能构成三角形；
- 三边相等：等边三角形；
- 恰有两边相等：等腰三角形；
- 其余：普通三角形。

# 格式

## 输入

一行三个整数 a b c，用空格分开（1 ≤ a, b, c ≤ 20）。

## 输出

一行，`不能构成三角形`、`等边三角形`、`等腰三角形` 或 `普通三角形`。

# 测例

```input1
3 4 5
```
```output1
普通三角形
```

```input2
1 2 3
```
```output2
不能构成三角形
```

```input3
6 6 6
```
```output3
等边三角形
```
